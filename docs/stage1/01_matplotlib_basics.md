# 阶段 1 · 第 1 节：Matplotlib 基础画图

Matplotlib 是 Python 里最基础、最通用的绘图库，负责把数字变成散点图、柱状图、折线图等可视化结果。你可以把它理解成「画布 + 画笔」：先建一张图，再往上画点和线，最后显示或保存成 PNG。在机器学习里，它常用来看样本分布、类别是否平衡、模型预测是否离谱；很多更高层的绘图库（如 Seaborn）底层也依赖它。

## 学习目标

- 画散点图观察两类样本
- 画柱状图看类别是否平衡
- 会把图保存成 PNG

## 直觉

1. **先画图再建模**：很多问题靠眼睛就能发现异常或可分性。
2. 两类在特征空间里若明显分开，简单模型往往就够用。
3. 类别极不平衡时，准确率会骗人，后面要用更合适的指标。
