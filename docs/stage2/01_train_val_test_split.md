# 阶段 2 · 第 1 节：训练 / 验证 / 测试划分

训练/验证/测试划分是监督学习里防止「自己给自己打高分」的基本纪律。训练集用来学规律，验证集用来选模型和调参，测试集只在最后评估一次、模拟上线后的真实表现。你可以把它理解成「习题 / 模拟考 / 期末考」：期末考卷不能提前拿来反复刷题，否则分数会虚高。sklearn 的 `train_test_split`（配合 `stratify`）就是完成这种划分的标准工具。

## 学习目标

- 理解 train / val / test 各自职责
- 会用 `train_test_split`，并使用 `stratify`
- 建立「测试集只最终用一次」的习惯

## 直觉

1. **训练集**：学参数；**验证集**：选模型/调参；**测试集**：最终打分。
2. 用测试集反复调参 = 泄漏，分数会虚高。
3. `stratify=y` 让各子集里正负类比例接近，分类任务几乎总要开。
