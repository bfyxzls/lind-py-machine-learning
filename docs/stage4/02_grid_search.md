# 阶段 4 · 第 2 节：网格搜索调参

网格搜索（Grid Search）是一种系统化的超参数调优方法：你预先列出候选组合（如不同的 `C`），让模型在训练集上用交叉验证逐一打分，选出最优组合。你可以把它理解成「按菜单穷举试吃」——全面但可能更耗时；更大搜索空间时可用随机搜索等替代。关键纪律是：搜索只看到训练集，测试集只在最后评估一次；在 Pipeline 里写 `步骤名__参数名`（双下划线）才能正确指定要搜的超参数。

## 学习目标

- 用 `GridSearchCV` 在 Pipeline 上搜超参数
- 遵守：搜索只在训练集，测试集最后评估一次

## 直觉

1. 超参数（如 `C`）不是数据学出来的，需要搜索或经验设定。
2. 网格搜索 = 穷举候选组合，用 CV 打分。
3. **数据泄漏高发点**：在全数据上调参，或把测试集卷入搜索。

## 运行
